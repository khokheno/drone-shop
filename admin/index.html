Import parts from CSV

Export a sheet from Excel, Numbers or Google Sheets as CSV. First row must be headers. Columns: name, category, price, stock, specs (separated by ; or |), description, condition (new or used; empty means new). Only name and price are required. Unknown categories are added automatically.
